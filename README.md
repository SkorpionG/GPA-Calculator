# GPA Calculator (成績計算網站)

A responsive, bilingual client-side web application for calculating semester GPA scores on a 4.3 grading scale, supporting both English and 繁體中文.

## Features

- **Interactive GPA Calculation**: Computes weighted GPA instantly from course credits and letter grades.
- **Dynamic Course Management**: Add, remove, and sort courses in ascending or descending grade order.
- **Persistent Storage**: Saves course entries, language preference, and intro animation preference in `localStorage`.
- **Bilingual Interface**: Real-time translation toggle between English and 繁體中文.
- **Reusable Navigation**: Shared `<site-header>` Web Component across all pages.

## Technologies

- HTML5
- CSS3 / SCSS
- Vanilla JavaScript (ES Modules & Web Components)
- GreenSock GSAP
- ESLint, Prettier, Husky, and `lint-staged`

## Local Preview

Open `index.html` with VS Code Live Server or run a local static server from the project root.
